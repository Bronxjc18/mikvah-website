# David Edelstein Mikvah website

Static copy of davidedelsteinmikvah.com (also davidedelsteinmikvah.org), made from the Squarespace site on November 11, 2026 for Rabbi Saadia Pewzner, Bronx Jewish Center.

- 6 pages (Home, About, Mikvah Facts, Updates, Contact, Donate) plus a thanks page and a 404 page
- All photos, the video and the fonts are stored in this folder; nothing loads from Squarespace
- Contact form: FormSubmit, sends to rabbi@bronxjewishcenter.org
- Donate: https://givebutter.com/DavidEdelsteinMikvah

It is a plain static site: these files can be served as-is by GitHub Pages or any static host.
